# 固件交付与测试

## 默认配置

固件版本为 0.5.0，系统使用 Buildroot 和 `5.10.160-rt77-mohism` 实时内核。默认请求原生双目 1280×800@120 采集、双目 USB 60Hz、深度计算与输出 30Hz。性能配置、带宽计算和运行统计见 [性能说明](performance.md)。

双目共用 FSIN，IMU 由 INT1 数据就绪中断读取。共同事件同步的 DEN、门控和反馈设计见 [同步方案](hardware-sync.md)。DEN 用于标记采样与外部事件的关系，ADC 采样相位仍由传感器时钟决定。固定采样相位方案可采用 IMU DRDY 经硬件分频后触发相机，并加入受控复位、门控及电平转换。

## 测试项目

| 项目 | 检查内容 |
| --- | --- |
| 硬件 | 电源时序、IO 电压、相机地址、器件封装、PCB 走线与 DRC |
| 启动 | DDR/SD 识别、启动日志、掉电与重启、固件哈希 |
| 同步 | 左右曝光时差、IMU 采样与触发事件偏移、温漂、错序与事件丢失处理 |
| 实时与性能 | 独立图像、深度及有效 VIO 更新率；延迟 P95/P99/最大值；丢帧、CPU、RSS 与温升 |
| USB | 双 UVC 与双 ACM 并发、主机兼容性、启停顺序、热插拔、帧完整率与时间戳 |
| 算法 | 相机/IMU 标定、多数据集 ATE/RPE、深度误差、在线标定收敛与地图重定位 |
| 故障恢复 | 传感器断开、采样溢出、USB 中断、磁盘写入失败、进程重启与看门狗 |
| 配置与升级 | 参数持久化、标定追溯、登录认证、升级失败恢复、版本回滚与许可证 |

相机、VIO、深度和 USB 并发运行时，使用 cyclictest 测量调度延迟，同时记录 IMU 间隔和端到端延迟。Wi-Fi 与编码模块使用相同 RT 内核配置重新构建。测试命令见 [实时内核](realtime.md)。

## 发布记录

每次发布关联硬件版本、序列号、Git commit、镜像 SHA256、标定摘要、测试配置和原始数据。`qualification/acceptance-draft.json` 保存指标草案；空值表示该项没有记录值。

帧率统计区分请求频率、独立帧数、重复缓冲和有效估计。精度记录注明数据集、坐标系、对齐方式和重置分段。调整配置后，使用相同负载和统计口径比较结果。
